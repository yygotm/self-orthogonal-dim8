# SO [97,8,≥46] の非存在：分類を使わない証明

## 0. 主張と使用する既知の定理

二元自己直交符号 C⊆F₂^97 で dim C=8、すべての非零語の重みが46以上、というものは存在しない。
零座標は許して出発する。下界の構成および ñ₂(8,46)≤98 は本証明の対象外である。

使用する既知の結果は Griesmer 限界 g(k,d)=Σ_{i=0}^{k−1}⌈d/2^i⌉ と、
Kurz 草稿の Proposition 1、Lemma 1–3、MacWilliams 恒等式（Proposition 2）、
および **Theorem 1（Griesmer 等号符号の可除性）** である。
最後の定理は草稿の印刷 p.3 にあり、「素数体上の Griesmer 符号で p^r|d なら p^r-divisible」と述べる。
草稿の出典は [65, Theorem 1]、H. N. Ward, *Divisibility of codes meeting the Griesmer bound*,
J. Combin. Theory Ser. A **83**(1), 79–93 (1998)（および [46], 二元の場合 [27]）。
ここでは草稿に記された定理を採用し、Ward 原論文の証明は再検証していない。n=g(k,d) の場合は g の狭義単調性により、実際の最小距離も下限dに等しい。
Solomon–Stiffler/Belov の分類定理、LinCode、既存の分類表、codetables は使わない。

証明の核は手の議論である。有理数の証明書は小さなモーメント系の検算を補う。
解くプログラムを実行し直す必要はなく、verify_final.py は標準ライブラリだけで検算する。
Griesmer/Ward/MacWilliams/Fourier の一般定理と、下記の符号から行列への対応自体は数学として読む部分であり、Lean 化はしていない。

## 1. 基本的な帰結

SO なら各語の重みは偶数で、q(x)=wt(x)/2 mod2 は線形である。
D=ker q=C₄ は二重偶部分符号である（草稿 p.4, Proposition 1）。
SO 符号の剰余符号は偶であるが、一般には SO とは限らない。
以下でも「剰余が偶」と「剰余が SO」を混同しない。
SO 性を再び使う場合には Ward による4可除性を先に示す。

SO [N,k,≥d] 符号 C の非零語の重み w<2d に対して、剰余は [N−w,k−1,≥r]、
r は d−w/2 以上の最小の偶数である。
親符号 C が全長なら、この剰余も全長である。
従って g(k−1,r)>N−w ならその重みは不可能である（Lemma 1,2）。
通常の偶符号からさらに剰余を取るときは、r を偶数に切り上げない。

全長コードの生成行列の同一点が m 回あれば、その点で短縮すると dim が1下がり長さが N−m になる。
従って最小重み d の k 次元コードなら N−m≥g(k−1,d)。
B₁ は零列数、B₂ は、零列どうしも含め、等しい列の非順序対 {i,j}（i≠j）の個数である。

## 2. 最小重み48以上の枝

g(8,48)=97 なので有効長は97。Lemma 1–3 と Griesmer により、
許される非零重みは48,64だけになる（全長 SO なので96=n−1も除く）。
MacWilliams の最初の2式から A₄₈+A₆₄=255、48A₄₈+64A₆₄=128·97、
従って A₄₈=244、A₆₄=11。
第3式は B₂=−9 となり矛盾する。
`final-certificate.json:min48` はこの矛盾の Farkas ベクトルを含む。
従って以下では C に重み46の語があり、dim D=7 としてよい。

## 3. 有効長と重複点

D は最小重み48以上、dim7 だから、有効長 L は g(7,48)=96 以上。
C の有効長を N とすると、(N,L) は (96,96),(97,96),(97,97) の3通り。

D を一点で短縮すると dim6、最小重み48以上なので L−m≥g(6,48)=95。
従って L=96 なら D は射影的、L=97 なら各点の重複度は高々2。
C を一点で短縮した SO dim7 コードには dim6 以上、最小重み48以上の二重偶部分符号があるので、
同じく N−m≥95。C も N=96 なら射影的、N=97 なら重複度は高々2。

L=96 のとき D は射影的で、C における重複列は D へ制限すると重複する非零列か、
2本の零列になる。D の非零列には重複がなく、D の零列は高々1本なので、C も射影的。
L=97 のときは、節5の分類により D の重複点はちょうど3点。
D⊆C より C⊥⊆D⊥ だから、C の重複点数 B₂(C) は0〜3の範囲である。

## 4. L=96 の D

Lemma 1,2 と Griesmer により D の非零重みは48,64,96。
D の射影性により B₁=B₂=0。最初の3つの MacWilliams 式の唯一の解は
A₄₈=124、A₆₄=3、A₉₆=0 である（証明書 D96）。

D の列は `F₂⁷\{0}` の96個の相異なる点である。その補集合 T は31点。
全単体符号では各非零汎関数の重みが64なので、T 上の重みは16か0。
T 上で消える非零汎関数は D の重み64の3語に対応する。
従って T の張る空間 U の余次元は2、dim U=5。
T は `U\{0}` の31点すべてであり、D の列集合は F₂⁷\U、すなわち U の3つの非零剰余類である。
これは列の幾何からの導出であって、Griesmer 符号の分類表の引用ではない。

## 5. L=97 の D を手で分類する

### 5.1 重み56・72・80を除く小さな補助結果

最初に残る D の重みは {48,52,56,64,68,72,80}（Lemma 1–3 と Griesmer）。

**[13,5,6] 偶コードは存在しない。** 全長は Griesmer 等号 g(5,6)=13 により強制される。
短縮の Griesmer 限界により射影的。通常の剰余限界で重み10を除くと、非零重みは6,8,12。
MacWilliams の total、1次モーメント、B₂=0 の式にそれぞれ18,−2,1を掛けて足すと
48A₁₂=64、すなわち3A₁₂=4。A₁₂ が整数なので不可能。
有理数 LP 自体は実行可能で、唯一の解は (A₆,A₈,A₁₂)=(68/3,7,4/3)。
これは Farkas の矛盾ではなく、整数性による矛盾である。

**[41,6,20] コードは存在しない。** g(6,20)=41、Ward より4可除、従って SO。
全長かつ射影的。剰余限界と Lemma 3 により重みは20,24,28,32。
重み28があると [13,5,6] 偶剰余が生じるので、前段で除く。
残る20,24,32について、total、1次モーメント、B₂=0 の式に140,−6,1を掛けると
192A₃₂=128、すなわち3A₃₂=2。整数性に反する。
有理数 LP の唯一の解は (154/3,11,2/3) である。
D の重み56を仮定すると剰余が [41,6,20] なので、D の重み56はない。

D の重み72では [25,6,12] の剰余となる。Griesmer 等号と Ward から4可除・SO。
Lemma 1–3 により重み12,16のみ。MacWilliams は A₁₂=52,A₁₆=11,B₂=−3 を与える。
重み80では [17,6,8] の剰余となり、Ward により8可除・SO。
全長 SO なので16=n−1はなく、重み8だけになり、最初の2つのモーメントが矛盾する。
いずれも短い有理数 Farkas 証明書（R25,R17）を残した。

### 5.2 重み68を2セルの split enumerator で除く

この段階の重み集合は48,52,64,68。重み68の c∈D を仮定する。
x と x+c を対にし、a=wt(x), b=wt(x+c) とおく。
台68座標と補集合29座標での重みは i=(68+a−b)/2、j=(a+b−68)/2。
SO から i は偶数。剰余は偶 [29,6,≥14] であり、さらにその通常の剰余に Griesmer を課す。
残る非自明の対は (a,b,i,j)=(48,48,34,14),(48,52,32,16) の2つだけ。
ゼロと c の対を除く両セル数を X,Y とする。D の128語は64対に分かれるので、
 X+Y=63。
D は全長・次元7なので、1次モーメントは Σ_{x∈D}wt(x)=2⁶·97=6208。
ゼロと c の対の寄与は68、各セルの1対の寄与は96,100だから、
 68+96X+100Y=6208、すなわち96X+100Y=6140。
全数の式を97倍してこの式を引くと、
 X−3Y=97·63−6140=−29。
従って X=40,Y=23。D の重み分布は48^103 52^23 68^1になるが、B₂=−1。

Farkas の整数結合は、次の3本の ≤ 不等式
 −X−Y≤−63,  −X+3Y≤29,  96X+72Y≤5368
にそれぞれ90,6,1を掛けるもの。左辺は0、右辺は−128。
これが `final-certificate.json:D68` の証明書（正の共通因子による規格化あり）。

### 5.3 重み分布と列集合の分類

D の非零重みは48,52,64。b=A₆₄、a=A₅₂ とすると
 a+4b=28,  A₄₈=99+3b,  B₂=3b−6。
よって b∈{2,3,4,5,6,7}、a∈{20,16,12,8,4,0}。

D のメッセージ空間を F₂⁷ と同一視する。
V は重み52のメッセージ a 点、W は重み64のメッセージ b 点の集合とする。
これらは相異なる非零点である。補助的な列多重集合 M を「V 各1回、W 各4回」で作る（長さ28）。
元の D の生成行列における非零列 y の重複度 m_D(y) を Fourier 逆変換すると
 `m_D(y)=(12−Σ_{u∈V}(−1)^{u·y}−4Σ_{u∈W}(−1)^{u·y})/16`
        =(wt_M(y)−8)/8  (y≠0)。
従って M は8可除、非零メッセージの重みは8以上、次元は7。

V への射影コードは全長・射影的で4可除。
M が8可除なので、V の任意の2語の台の共通部分の大きさは4の倍数。
V に重み4の語があれば、その台4座標上で他のすべての語は0か全1となり、4列が同じ点になってしまう。
射影性に反するから V の非零重みは8以上。

この交差可除性から wt(v)/4 mod2 は V 上の線形写像。
その核を V₈ とし、この写像が非零だと仮定する。
核でゼロとなる座標は商 V/V₈ の唯一の非零汎関数に対応するため、V の射影性より高々1座標。
V₈が恒等的に零となる座標数をzと置くと、射影性からz≤1。従って V\V₈ の平均重みは (a+z)/2≤(20+1)/2=10.5。
一方各語は4 mod8で重み4を持たないので12以上。矛盾。
よって V 自体が8可除で、非零重みは8,16だけ。

a>0、r=dim V とする。射影的な8可除コードの最初の3モーメントを消去すると
 a²−47a+512=2^(9−r)。
a∈{4,8,12,16,20}、1≤r≤7 での唯一の解は (a,r)=(16,5)。
a=0 の場合は M=4W。8可除性から W は偶コードだが、長さ7の偶コードは次元≤6なので M の次元7に反する。
従って b=3、D の重み分布は48^108 52^16 64^3、B₂=3。

V は [16,5,8]、射影的、重み分布8^30 16^1。
重み16の語に対応する汎関数が V の全16点で1なので、V は5次元空間のアフィン超平面全体。
M が8可除かつ V も8可除なので、W の射影は長さ3の偶コード。
3点は相異なる非零点だから dim W=2、W は2次元空間の全非零点。
dim M=7=5+2 より両射影は独立、列空間は直和に分かれる。

従って非零列を y=(a,t,b)、a∈F₂、t∈F₂⁴、b∈F₂² と書ける。
上の m_D(y) から、D の全97座標は次の列である。
- b≠0 の3ブロックそれぞれ：t≠0 に対する (0,t,b),(1,t,b) が各1回（30座標）、(1,0,b) が2回。
- 追加の1座標：(1,0,0)。
これは同値を除いて一意で、LinCode からの候補入力は使っていない。
verify_final.py はこの列集合から128語だけを生成し、48^108 52^16 64^3 と SO 性の正の対照を確認する。

## 6. 4個の整数だけに関する Fourier 補題

G=F₂² の非零3点 j に実数 T_j を置き、`S_β=Σ_{j≠0}(−1)^{β·j}T_j` とする。
Σ_β S_β=0。もし S_β≤H かつ S_β≡H mod8 なら `S_β=H−8z_β`、z_β≥0整数で、Σz_β=H/2。
非零 j について `T_j=(1/4)Σ_β(−1)^{β·j}S_β=−2Σ_β(−1)^{β·j}z_β`。
従って
- H=4 なら T_j∈{−4,0,4}。
- H=6 なら T_j∈{−6,−2,2,6}。
後者は和が3なので符号和が奇数になることから従う。分類探索は不要である。
検算では和が2または3の4変数の組を、10個・20個だけ列挙する。

## 7. D の有効長96から C を除く

節4の3つの U 剰余類上で、C\D の代表の符号列を s_j:U→{±1}、|U|=32 とする。
`T_j(v)=Σ_{x∈U}s_j(x)(−1)^{v·x}` とおく。

N=96 の場合、C\D の重みは2 mod4で46以上なので、その長さ96の Walsh 値は4 mod8で4以下。
固定した v について、4つの商指標 β に節6を H=4 で適用できる。
従って各 T_j(v) の絶対値は高々4。
しかし Parseval より Σ_v T_j(v)²=32²=1024、一方高々32·16=512。矛盾。

N=97 の場合、D の唯一の零座標で C\D の語は1。
長さ96の Walsh 値は6 mod8で6以下となり、節6の H=6 を適用する。
各 T_j(v)∈{±2,±6}。任意に j を固定し、s=s_j と書く。
Parseval から |T|=6 が28本、|T|=2 が4本であり、ΣT⁴=36352。
T(0)=32−2wt(s の負符号集合) は2 mod4なので、その負符号集合は奇数サイズ。
非零 h について R(h)=Σ_x s(x)s(x+h)=32−4m_h。
m_h は {x,x+h} の不一致ペア数で、負符号集合のサイズと同じ偶奇。従って R(h)≡4 mod8、R(h)²≥16。
R(0)=32 と Fourier の4次モーメント恒等式から
 Σ_v T(v)⁴=32Σ_h R(h)²≥32(32²+31·16)=48640。
36352<48640 と矛盾する。

## 8. D の有効長97から C を除く

節5の3つの32座標ブロックと、追加の1座標を使う。
C\D の代表は、D の a に対応する行を足すことで追加座標を0にできる。その符号を+1に固定する。
各ブロック j と t≠0 について、(0,t,j),(1,t,j) 上の符号を s₀(t),s₁(t) と書く。
t=0 の重複2座標上の符号を `s_A(0),s_B(0)` とする。

P(t)=s₀(t)+s₁(t), Q(t)=s₀(t)−s₁(t) (t≠0)、
`P(0)=s_A(0)+s_B(0)`, Q(0)=−P(0) とおく。
指標を τ∈F₂⁴ と書き、P̂(τ)=Σ_t P(t)(−1)^{τ·t}、Q̂(τ)=Σ_t Q(t)(−1)^{τ·t} とする。
D のメッセージで a=0 のときブロックの Fourier 係数は P の変換、a=1 のときは Q の変換である。
C\D の全体の Walsh 値は97−2wt(c)≤5、かつ5 mod8。
追加座標の寄与は a=0 なら+1、a=1なら−1。
従って、固定した指標 τ に対し、商 F₂² の4指標で節6をそれぞれ H=4,H=6 として使える。
P の16個の Fourier 係数の絶対値は≤4、Q の係数は≤6。
Parseval により
 Σ_t P(t)²≤16、Σ_t Q(t)²≤36。
ところが t≠0 の15ペアでは P(t)²+Q(t)²=4、t=0 では2P(0)²≥0なので
 Σ_t(P(t)²+Q(t)²)≥60。
上界16+36=52と矛盾する。

節2,7,8はすべての有効長と最小重みの枝を網羅する。従って SO [97,8,≥46] は存在しない。短いコードには零座標を加えられるので ñ₂(8,46)≥98 も従う。□
